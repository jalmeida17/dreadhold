**Dreadhold v0.2.1: talk to your ally.**

**▶ [Play in your browser](https://dreadhold.vercel.app)**, or download the desktop build below.

| Platform | File | How to start |
|---|---|---|
| Windows 10/11, 64-bit | `Dreadhold-v0.2.1-windows-x86_64.zip` | Unzip, run `Dreadhold.exe` |
| Linux, 64-bit | `Dreadhold-v0.2.1-linux-x86_64.tar.gz` | Extract, run `./Dreadhold.x86_64` |

The builds are not code-signed: on Windows, if SmartScreen says *"Windows protected your PC"*, click
**More info**, then **Run anyway**.

## New

- **Duo chat**: in a duo vigil, press `Enter` to talk to your ally (`Enter` sends, `Esc` cancels); the
  messages show on the left and fade after a few seconds. The Duo Hall has its own chat line, so you can
  agree on a battlefield before the vigil begins.

## Fixes

- In duo, the boss bar is no longer hidden under your ally's frame: the ally frame moved to the top right.
